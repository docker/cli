# docker pull

<!---MARKER_GEN_START-->
Download an image from a registry

### Aliases

`docker image pull`, `docker pull`

### Options

| Name               | Type     | Default | Description                                                              |
|:-------------------|:---------|:--------|:-------------------------------------------------------------------------|
| `-a`, `--all-tags` | `bool`   |         | Download all tagged images in the repository                             |
| `--dry-run`        | `bool`   |         | Check if a newer image is available without pulling                      |
| `--format`         | `string` |         | Format output of --dry-run using a custom template: 'json' or 'TEMPLATE' |
| `--platform`       | `string` |         | Set platform if server is multi-platform capable                         |
| `-q`, `--quiet`    | `bool`   |         | Suppress verbose output                                                  |
